# CourseHub - Online Learning Platform

CourseHub is a full stack online learning platform built with modern web technologies.

## Project Overview

CourseHub allows users to explore courses, enroll in lessons, track learning progress, and manage their accounts through a modern responsive interface.

## Technologies

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- Redux Toolkit
- React Router
- Axios
- Lucide React

## Features

- User authentication
- Browse courses
- Course details
- Learning dashboard
- Course progress tracking
- Wishlist management
- Responsive design
- Modern UI components
